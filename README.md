# Excellent Heights Academy Website

**Student:** Oguejiofor Oluebube Victor

## Project description
A six-page information website for Excellent Heights Academy, a private school offering creche, nursery, primary, junior secondary and senior secondary education, with computer education and science and technology programmes.

## Objectives
- Build a multi-page website with a professional navigation system.
- Use semantic HTML elements, lists, tables, forms, images and video.
- Apply CSS selectors, the box model and Flexbox.
- Make the site work on desktop and mobile screens.
- Publish the site using GitHub Pages.

## Technologies used
HTML5, CSS3, Git and GitHub Pages. No JavaScript or frameworks.

## Pages
index.html (Home), about.html (About Us), academics.html (Academics), admission.html (Admissions), activities.html (School Activities), contact.html (Contact Us)

## Features developed
- Shared header, navigation and footer on every page
- Welcome banner, school motto, school levels and three featured announcements
- Admission application form with 12 fields, labels and required attributes
- Weekly timetable using table headings, colspan and rowspan, plus a school calendar
- Six activity cards, each with an image, title and description
- Embedded school tour video and Google Map
- Hover and focus effects, and a responsive layout for mobile screens

## Challenges encountered
1. Making the timetable use both colspan and rowspan correctly.
2. Fitting a long admission form and wide tables on small screens.
3. Keeping image, video and CSS paths correct for GitHub Pages.

## How the challenges were resolved
1. Planned the table grid on paper first, then added a title row (colspan) and a break column (rowspan).
2. Used Flexbox wrapping, scrollable table containers and a media query.
3. Used lowercase file names and relative paths with forward slashes.
